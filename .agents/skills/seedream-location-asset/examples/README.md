# Example Images

This folder stores canonical example assets for the
`seedream-location-asset` skill.

Current example:
- `pirate-location.png`: pirate-era below-deck captain's cabin interior. It was
  generated from an earlier version of the maritime prompt in
  `../references/worked-examples.md`; that reference lists what the current
  prompt changes.

When updating the skill, keep the worked example aligned with this image so
future agents can reuse it consistently.
