# Observed Failures

Read [the entrypoint](../SKILL.md). This is a log of actual Seedance 2.5
native-audio outputs, not hypothetical cases. Use it to anticipate risk and to
choose what to check in listening. It does not prove a word is unsuitable, and
it does not establish the correct pronunciation.

Evidence level: speech-to-text transcripts plus model-based listening
(`seed_audio_understand`) on 1080p, 9:16, English-dominant Taglish takes,
September 2026. No native-speaker confirmation.

## Patterns

- Whispered and shouted positions produced most errors. Normal-volume,
  mid-sentence placement produced the fewest.
- Word-initial Tagalog after a pause was garbled more than the same word
  inside a sentence.
- One targeted note fixed an English/Tagalog confusion ("Hoy" vs "Hey"). The
  same approach did not fix a long word in a shouted position.
- Contractions such as *'ng* may be normalized to a fuller spoken form. Decide
  whether that variant is acceptable before spending a retake.

## Using this log

1. For a locked line containing a pattern above, flag it as a listening
   priority in the review plan. It is not a reason to rewrite without scope.
2. If rewriting is in scope, propose moving the critical word mid-sentence at
   normal volume, as a draft for the user to accept.
3. After a new take, add a row with the locked text, what was heard, the note
   tried, and the result.
