# Frame Break Scenes and Subjects

These are generic design examples and optional techniques, not results from
previous takes or validation claims. Adapt them to the current brief.
The prompt blocks stay in [the entrypoint](../SKILL.md) and
[the template](prompt-template.md).

## Scenic Backdrop

| Design concern | Technique to try |
| --- | --- |
| Scene competes with the overlay | Confine it to the central window; keep long horizontal objects away from bar edges |
| Crossing silhouette is unclear | Choose a calmer, darker backdrop with a different hue or value from the subject; inspect actual contrast |
| Camera lock is hard to judge | Include fixed background features and distinguish slow ambient motion from camera movement |
| Unwanted lettering or effects | Simplify signs, packaging and equipment; inspect for logos, glow and flare rather than assuming exclusions worked |
| Depth is unclear | Use a readable background distance, such as a fictional courtyard, while keeping the subject inside the window between crossings |

Compose lighting, lens and grade only when requested; do not add unused axes.

## Subject Types

For every subject, plan fixed straight bars, an opening inside the window, one
coherent action per stage and a return after each named crossing. Choose the
crossing count from the brief, not from presumed model reliability by style.

| Subject | Generic staging example |
| --- | --- |
| Illustrated character | Name the art style and select a hand, boot or cape edge for each crossing; bind the identity reference without its sheet layout |
| Flat graphic character | Use a simple crossing silhouette and inspect whether the outline remains complete |
| Stylised 3D mascot | Keep inactive parts behind the acting part; compare limb scale and markings against the reference |
| Photoreal person | Try a raised palm for the upper bar and a coat hem for the lower bar, with an explicit return inside |
| Photoreal animal | Choose anatomically plausible actions and inspect whether the crossing part or head is clipped |
| Product | Use [product hero](product-hero.md): one product defined by its photos, no person or hand, text-free footage |

No example promises a crossing, fixed geometry or a particular success rate.
